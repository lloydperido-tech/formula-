🚀 WORKFLOW SUMMARY

Student Request Process:
  1. Student logs in → s_request.html
  2. Selects document template (dropdown)
  3. Form fields appear dynamically
  4. Fills required fields
  5. Specifies quantity
  6. Sees real-time cost calculation
  7. Clicks "Submit Request"
  8. API creates request with reference number
  9. Redirected to success.html
  10. Shows reference number & payment instructions
  11. Student goes to cashier with reference number
  12. Pays and gets receipt
  13. Goes to s_track.html (later enhancement)
  14. Uploads payment receipt
  15. Request status changes to "Payment Submitted"

Admin Verification Process:
  1. Admin logs in
  2. Views request queue (admin/dashboard.html - Phase 5)
  3. Sees requests with "Payment Submitted" status
  4. Reviews receipt image
  5. Clicks "Verify" button
  6. Request status changes to "Payment Verified"
  7. Admin prepares document
  8. Updates status to "Processing"
  9. When ready, updates to "For Release"
  10. Student collects document
  11. Status updated to "Completed"
